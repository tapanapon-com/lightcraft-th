# LightCraft TH Version Log

## 0.20.0-th.1 — preparing native release

ฐานต้นฉบับ [v0.20.0](https://github.com/storytold/lightcraft/releases/tag/v0.20.0) เผยแพร่ 9 พฤศจิกายน 2026 ที่ `192ff72923c39e6623f2c7ff67ab3a119deb8071`

รวมซอร์สและประวัติต้นฉบับ พร้อมคำแปลไทย 4,180 รายการ กำลังตรวจ native Mac/Windows ก่อนเผยแพร่ตัวติดตั้ง รายงานผลตรวจฉบับเต็มจะบันทึกหลังผ่านทั้งสองแพลตฟอร์ม

## ก่อนรุ่นนี้

Repository เดิมเป็นเอกสาร รุ่น 0.19.0-th.1 เคยตรวจบนเครื่องแต่ไม่ได้เผยแพร่ Release เนื่องจากต้นฉบับออก v0.20.0 ก่อนเริ่ม Windows build จึงย้ายฐานมา 0.20.0 ก่อนเผยแพร่
